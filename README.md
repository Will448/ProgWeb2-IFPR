# 🎯 Objetivo

O MEPI tem como objetivo centralizar e facilitar o gerenciamento de:

* Funcionários
* Cargos
* Férias
* Equipamentos (EPIs)

O sistema busca resolver dificuldades no controle e organização dessas informações dentro de empresas.

---

# ⚙️ Funcionalidades Principais

* 👤 Cadastro, edição e exclusão de funcionários
* 🏢 Gerenciamento de cargos
* 🏖️ Controle de férias
* 💰 Simulação simples de folha de pagamento
* 🦺 Cadastro de equipamentos (EPIs)
* 🔄 Registro de entrega de equipamentos para funcionários
* 📊 Visualização dos equipamentos vinculados a cada funcionário

---

* Bootstrap 5
* JavaScript

---

# 🏗️ Estrutura do Projeto

O sistema foi desenvolvido utilizando o padrão **MVC (Model-View-Controller)**:

* **Model:** responsável pelos dados
* **Controller:** regras de negócio
* **View:** interface com o usuário

Essa organização facilita manutenção e evolução do sistema.
